| Module | Focus | Status |
|---|---|---|
| 00 Platform Core | Tenant, project, WBS/CBS, permissions, audit, integrations | Foundation |

| 02 Forecast Intelligence | ETC, EAC, scenarios, forecast drivers | Defined |

## Standard package per module

Each module has a PRD, architecture definition, UI/UX specification, agentic design, database model, API contract outline, testing strategy, and backlog.
