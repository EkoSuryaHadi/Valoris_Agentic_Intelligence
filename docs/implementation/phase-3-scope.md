# Phase 3 — Forecast & EVM

Forecast domain foundation is implemented with `EAC = AC + ETC` and `VAC = BAC - EAC`. Negative financial values and locked/closed periods are rejected. Existing EVM formulas cover PV, EV, AC, CPI, SPI, CV, and SV. Remaining integration work: forecast persistence, period workflow API, progress UI, EVM snapshots, and S-Curve.
