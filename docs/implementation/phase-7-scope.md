# Phase 7 — Reporting & Executive Intelligence

The read-only executive summary domain contract reconciles budget, approved changes, commitments, actual cost, ETC/EAC, VAC, and risk exposure into a single dashboard payload. Health is `AT_RISK` when CPI/SPI is below 0.90 or VAC is negative; otherwise `ON_TRACK`. UI cards, drill-down reports, exports, and production hardening remain integration work.
