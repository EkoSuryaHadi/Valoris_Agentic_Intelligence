# Module 01 — Cost Management UI/UX

## Navigation

- Cost Overview
- Budget & Baseline
- Commitments
- Actuals
- Accruals & Adjustments
- Variance Analysis
- Reconciliation
- Period Close

## Essential screens

1. Cost control tower with budget, commitment, actual, accrual, and variance.
2. Baseline version comparison.
3. Cost ledger with source and coding details.
4. Variance drill-down by WBS/CBS, vendor, category, and period.
5. Reconciliation workspace.
6. Period-close checklist and sign-off.

## UX principles

- Show amount, currency, period, and data freshness together.
- Distinguish approved, pending, rejected, and adjusted values.
- Let users drill from KPI to transaction evidence.
- Explain variance with plain-language drivers.
- Make irreversible actions require explicit review.
- Never hide data-quality warnings behind charts.

## Important states

Loading, partial data, stale source, unreconciled, period locked, approval pending, import rejected, and no baseline configured.
