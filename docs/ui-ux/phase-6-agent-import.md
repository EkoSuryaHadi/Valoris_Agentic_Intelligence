# Phase 6/8 UI — Agent Findings & Import Center

Agent Findings uses evidence-linked cards with severity, confidence, source references, recommended action, and review history. Human actions are Accept, Dismiss, or Escalate; no chat interface and no automatic approval.

Import Center uses Upload → Map → Validate → Preview → Commit. Preview separates valid and invalid rows, shows row-level errors, duplicate/unmapped references, and requires an explicit human commit. Invalid rows are never silently imported.
