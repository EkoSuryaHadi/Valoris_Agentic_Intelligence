# Module 05 — Risk-to-Cost Intelligence UI/UX

## Essential screens

- Risk-cost heatmap\n- exposure register\n- contingency view\n- scenario simulation\n- mitigation tracker

## UX principles

- Keep active organization, project, period, and currency visible.
- Show status, freshness, confidence, owner, and source beside key results.
- Let users drill from summary to evidence.
- Separate recommendation from approved decision.
- Preserve filters and user work when validation fails.
- Make warnings actionable and explain the next safe step.

## Required states

Loading, partial data, stale data, no baseline, validation issue, approval pending, rejected, locked period, and no results.
